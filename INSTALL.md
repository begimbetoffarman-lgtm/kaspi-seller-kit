# Установка Kaspi seller kit (инструкция для Claude Code)

Выполняй шаги по порядку. После каждого шага проверяй результат командой и пиши пользователю
одну строку: «шаг N: готово / не получилось, потому что…». Пользователь не программист:
объясняй простыми словами, команды запускай сам, а не проси его их печатать.

**Нельзя:** вводить пароли, логиниться за пользователя, обходить капчу, покупать, писать
поставщикам, коммитить и пересылать ключи. Вход в 1688 и любые платные подключения делает человек.

## 1. Проверка окружения

Определи систему (Windows / macOS / Linux) и проверь `git --version`, `node --version`, `npm --version`.

- Нет git или Node.js: скажи, что именно поставить (Git: https://git-scm.com, Node.js LTS: https://nodejs.org),
  дождись установки и перезапусти проверку. Сам из интернета ничего исполняемого не скачивай.
- Нужен Node.js 18 или новее.

## 2. Скачать репозиторий

Репозиторий: `https://github.com/begimbetoffarman-lgtm/kaspi-seller-kit`

```bash
git clone https://github.com/begimbetoffarman-lgtm/kaspi-seller-kit ~/kaspi-seller-kit
```

Папка уже есть: `git -C ~/kaspi-seller-kit pull`.

Не склонировалось: покажи ошибку дословно и остановись.

## 3. Запустить установщик

Windows (PowerShell):

```powershell
powershell -ExecutionPolicy Bypass -File "$HOME\kaspi-seller-kit\install.ps1"
```

macOS / Linux:

```bash
bash ~/kaspi-seller-kit/install.sh
```

Установщик сам: копирует навыки в `~/.claude/skills`, создаёт базу товаров `~/kaspi-agents`
с шаблонами и `CLAUDE.md`, ставит `1688-cli`. Существующее не перезаписывает. Хочет перезаписать
(обновление): добавь `-Force` / `--force`, но только после согласия пользователя.

Проверка: в `~/.claude/skills` есть `tovarka-agents` и `подбор-поставщика`; в `~/kaspi-agents`
есть `CLAUDE.md`, `Templates`, `Products.base`; `1688 --help` отвечает.

## 4. Подключения, которые делает человек

Скажи пользователю по каждому пункту, зачем он нужен, и что нажать. Не настаивай на платном.

1. **Вход в 1688 по QR-коду.** Запусти `1688 --help`, найди команду входа (login) и выполни её;
   покажи пользователю QR, он отсканирует приложением 1688/Taobao. Без входа поиск поставщиков не работает.
   В PowerShell команду называть через `& 1688 ...`.
2. **Redstat (по желанию, платный).** Данные по продажам и нишам Kaspi. Навык `tovarka-agents`
   использует его инструменты. Нет подключения: навык работает через веб-поиск, данные менее надёжны.
3. **Obsidian (по желанию, бесплатно).** Открыть папку `~/kaspi-agents` как хранилище, чтобы видеть таблицу
   товаров с маржой. Без него всё работает, просто карточки лежат обычными файлами.

## 6. Сквозная проверка

1. Попроси у пользователя ссылку на один его товар на Kaspi (или возьми любую карточку).
2. Запусти `/подбор-поставщика` на этом товаре: достаточно дойти до шага «эталон Kaspi» и поиска на 1688.
   На 1688 не больше двух поисков, при ползунке остановись.
3. Покажи результат и честно скажи, что проверено, а что нет.
