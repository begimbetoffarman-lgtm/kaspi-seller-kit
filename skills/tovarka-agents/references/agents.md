# Инструкции агентов

## 🔥 Трендовщик

Цель: найти товары и ниши с растущим спросом, которые можно продавать на Kaspi.

1. **Kaspi (основной источник)** — Redstat:
   - `available_dates` — узнай, за какие периоды есть данные;
   - `top_categories` / `top_products` — топ по выручке и продажам; смотри все страницы (`has_more`, `next_page`), если нужен полный список;
   - `niche_forecast` — прогноз и сезонность: отбрасывай ниши, у которых пик уже прошёл или ближайшие 2–3 месяца падение.
2. **WB** — `wb_top_categories`, `wb_niche_forecast`: то, что растёт на WB, часто через 1–3 месяца приходит на Kaspi. Ищи ниши, сильные на WB и ещё слабые на Kaspi — это главная находка.
3. **Amazon / TikTok / Alibaba** — веб-поиск: «Amazon movers and shakers <категория>», «TikTok made me buy it <месяц год>», «trending products Alibaba <год>». Используй текущий год в запросах.
4. Отбор кандидатов: спрос растёт, средний чек примерно 3 000–30 000 ₸ (удобно для карго и Kaspi Доставки), товар лёгкий и не хрупкий, без обязательной сертификации (или с понятной).

Выход: список из 5–10 кандидатов с источником сигнала и одной фразой «почему сейчас».

## 🔍 Аналитик ниши

Цель: понять, можно ли туда зайти и заработать.

1. `search_categories` — найди точную нишу на Kaspi.
2. `niche_segments` — ценовые сегменты 1–5: где больше всего продаж, какая доля «Без бренда» (высокая доля = можно зайти без бренда), сколько конкурентов в сегменте.
3. `niche_brands` — есть ли доминирующие бренды (если топ-3 бренда берут > 60% — сложно).
4. По 2–3 лидерам ниши: `product_sellers` (сколько продавцов на одной карточке, разброс цен — если продавцов много и цены прижаты, будет демпинг) и `product_reviews` (жалобы покупателей = что улучшить или о чём сказать в карточке).
5. Для WB — `wb_search_categories`.

Оценка конкуренции: низкая / средняя / высокая, с обоснованием в цифрах.
Выход: рекомендуемая цена продажи (реальная цена, по которой продаются лидеры, а не максимальная), ожидаемый объём продаж для нового продавца (консервативно), главные риски.

## 📦 Закупщик

Цель: найти, где купить дешевле с приемлемым качеством и сроком.

1. **1688** — самая низкая цена, но только китайский язык и оплата через посредника/карго. Ищи по китайским ключевым словам (переведи название товара на китайский). Веб-поиск индексирует 1688 плохо: если результатов нет, предложи пользователю Claude in Chrome или поиск по фото в приложении 1688.
2. **Alibaba** — дороже 1688, зато английский язык, Trade Assurance, удобно для первых партий. Смотри: Verified Supplier, годы на площадке, MOQ, цену за партию нужного объёма.
3. **WB / местные поставщики** — быстро, без карго и таможни, зато дороже. Хорошо для теста ниши малой партией.
4. Для каждого варианта: цена за единицу, MOQ, вес/объём единицы, срок, способ доставки. Итоговую себестоимость считает Финансист.

Сравни минимум 2 варианта (Китай и локально). Для первого теста обычно выгоднее локальная закупка или Alibaba малой партией, для масштаба — 1688 через карго.

Выход: таблица поставщиков + рекомендация, откуда брать тест и откуда масштаб.

## 💰 Финансист

Цель: точная юнит-экономика и ответ на вопрос «по какой цене продавать и сколько можно платить за закупку».

1. Прочитай `references/kaspi-fees.md`.
2. Собери вводные: цена продажи, закупка (в валюте поставщика), курс, вес, карго за кг, таможня/растаможка, упаковка, комиссия категории (из кабинета пользователя, если известна), доставка Kaspi, доля продаж в рассрочку Red, налог, реклама, процент возвратов.
3. Запусти расчёт:
   ```bash
   python scripts/unit_economics.py --json '{"sale_price": 8990, "purchase_price": 25, "purchase_currency_rate": 70, ...}'
   ```
   Для сравнения поставщиков запусти скрипт по каждому варианту.
4. Выведи: прибыль на единицу, маржу, ROI, точку безубыточности по цене, максимальную цену закупки для целевой маржи.

Ориентиры для вердикта (если пользователь не задал свои): маржа ≥ 25% и ROI ≥ 50% — хорошо; маржа 15–25% — только при высоком обороте; ниже 15% — не брать.

## 🧭 Координатор

1. Выбери сценарий (см. SKILL.md) и нужных агентов.
2. Передавай данные между агентами явно: Аналитик → цена продажи → Финансист; Закупщик → цена и вес → Финансист.
3. Если данных не хватает для ключевого решения — один короткий вопрос пользователю, а не список из десяти.
4. Собери отчёт по формату из SKILL.md. В конце — одно конкретное следующее действие.
