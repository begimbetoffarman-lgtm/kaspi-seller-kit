# Kaspi seller kit: правила для Claude Code

Проект помогает продавцу на Kaspi.kz находить товары, сверять поставщиков на 1688 и считать маржу.

**База товаров:** `~/kaspi-agents` (папки Niches, Products, Suppliers, Templates; открывается как хранилище Obsidian).
Если инсталлятор положил базу в другое место, путь записан в строке ниже.
База товаров: __VAULT_PATH__

## Команды

| Команда | Что делает |
|---|---|
| `/подбор-поставщика` | товар с Kaspi → поставщик на 1688 → сверка по фото → маржа |
| `tovarka-agents` (по фразам «что продавать», «проанализируй нишу», «посчитай маржу») | тренды, анализ ниши, поиск поставщика, юнит-экономика с комиссиями Kaspi |

## Правила работы

1. **Фото сверяется до расчёта.** Прибыль считается только по варианту 1688, который по фото и
   характеристикам совпал с карточкой Kaspi. Если не сверено, так и пиши.
2. **Курс юаня живой** с https://ifin.kz/exchange/aktobe/CNY (колонка «Продажа»; другой город:
   замените `aktobe`). В карточках курс устаревает, из них не брать. Не открылась страница: спроси курс.
3. **Не выдумывать цифры.** Продажи, цены, комиссии, тариф карго: из источника, от пользователя
   или явно помечено «допущение».
4. **Допущения называть вслух:** карго, налоги, НДС на комиссию, реклама, возвраты, пока не даны.
5. **В отчёте по поставщику обязательны ссылки:** предложение 1688 (`detail.1688.com/offer/<id>.html`) и магазин.
6. **Антибот 1688:** ползунок или `punish` значит остановиться и сказать пользователю. Капчу не обходить, не повторять запросы.
7. **Деньги и сообщения только по команде:** не писать поставщику, не заказывать, не платить.
8. **Стиль ответов: коротко и ясно.** Таблица и 3–5 строк выводов, подробности по запросу.
9. **Секреты** (токены, ключи, вход в 1688) не коммитить и не пересылать.

## Если что-то не работает

- `1688` не найден: `npm i -g 1688-cli`, потом вход по QR (делает человек).
- Redstat не подключён: `tovarka-agents` работает через веб-поиск, но данные менее надёжны, так и пиши.
- Реальность разошлась с этим файлом (поменялся сайт, команда): скажи прямо и предложи поправить файл.
